## Link rules

1. Keep each investigation's evidence ledger, timeline, source acquisition records, and findings in its own folder.
2. A single source artifact relevant to both tracks should retain one canonical source identity and be cross-referenced by evidence ID; do not pretend duplicate copies are independent corroboration.
3. Create a link record only when a specific source, transaction, person, entity, or event is materially relevant to both investigations.
4. Record link type: shared source, shared entity, shared transaction, shared event, or analytical lead.
5. Record direction and confidence. Distinguish documented fact from an investigative hypothesis.
6. A link between investigations does not prove causation, coordination, control, wrongdoing, or common purpose.
7. Do not merge timelines automatically. Each timeline remains independently maintained; a parent-level index may point to both.
8. Reconcile conflicting claims in the source investigation first. Cross-link the conflict rather than silently harmonizing it.
